2. 터치 이벤트 대응 & Capacitor 번들링 팁 (실전 가이드)
바닐라 JS 게임을 Capacitor로 모바일 앱화할 때 가장 중요한 5가지 핵심 팁을 묶어서 정리해 드립니다.
① 클릭 지연 제거 및 레이아웃 고정 (CSS)
모바일 웹뷰는 기본적으로 터치 시 '클릭'인지 '줌/스크롤'인지 판단하기 위해 약 300ms를 대기합니다. 게임에서는 치명적이므로 아래 설정을 반드시 넣으세요.
css
html, body {
  /* 스크롤 방지 및 화면 고정 */
  touch-action: none; 
  position: fixed;
  overflow: hidden;
  /* 텍스트 선택 방지 */
  user-select: none;
  -webkit-user-select: none;
}

.button {
  /* 클릭 시 생기는 파란 하이라이트 제거 */
  -webkit-tap-highlight-color: transparent;
  /* 터치 지연 제거 */
  touch-action: manipulation;
}
코드를 사용할 때는 주의가 필요합니다.

② 'Click' 이벤트와 'Touch'의 조화
게임 버튼에 touchstart를 직접 연결하면 스크롤이나 스와이프 도중에 버튼이 눌리는 버그가 생깁니다.
팁: CSS에서 touch-action: manipulation;을 설정했다면, JS에서는 그냥 click 이벤트를 쓰셔도 충분히 빠릅니다.
정밀한 조작(조이스틱 등)이 필요할 때만 touchstart, touchmove, touchend를 사용하세요.
③ Capacitor 파일 경로 (가장 잦은 실수)
Capacitor는 index.html을 기준으로 로컬 서버를 돌립니다.
금지: <script src="/js/app.js"> (루트 경로 / 사용 금지)
권장: <script src="js/app.js"> 또는 <script src="./js/app.js"> (상대 경로 사용)
이미지 파일 5개도 마찬가지로 반드시 상대 경로로 호출해야 화면에 나타납니다.
④ 하드웨어 뒤로가기 버튼 대응 (Android)
Capacitor 앱에서 안드로이드 뒤로가기 버튼을 누르면 앱이 그냥 꺼져버립니다. 바닐라 JS 환경에서 이를 제어하려면 아래 코드를 추가하세요.
javascript
import { App } from '@capacitor/app';

App.addListener('backButton', () => {
  if (confirm("게임을 종료하시겠습니까?")) {
    App.exitApp();
  }
});
코드를 사용할 때는 주의가 필요합니다.

⑤ 실시간 디버깅 (Chrome Inspect)
출시 전 가장 중요한 과정입니다.
안드로이드 폰을 PC에 연결하고 'USB 디버깅'을 켭니다.
PC 크롬 주소창에 chrome://inspect/#devices를 입력합니다.
실행 중인 내 앱의 'inspect' 버튼을 누르면, PC에서 모바일 화면의 콘솔(Console) 로그와 요소를 실시간으로 볼 수 있습니다.
요약:
사용자님의 코딩 스타일(Closure, 객체 리터럴)은 매우 정석적입니다. 위 CSS 설정과 상대 경로 규칙만 잘 지키시면 Capacitor 번들링 과정에서 큰 문제 없이 부드러운 게임 경험을 제공할 수 있을 것입니다.
